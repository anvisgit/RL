# Applied Reinforcement Learning

A growing collection of Reinforcement Learning (RL) implementations, experiments, and projects using Python and Gymnasium/OpenAI Gym environments. This repository serves as a hands-on exploration of modern RL algorithms, from classical methods to deep reinforcement learning.
## Current Environments

- CartPole-v1
- BipedalWalker
- Ant-v4

## Planned Additions

### Algorithms
- Q-Learning
- SARSA
- Deep Q-Network (DQN)
- Double DQN
- Dueling DQN
- PPO (Proximal Policy Optimization)
- A2C / A3C
- DDPG
- TD3
- SAC (Soft Actor-Critic)
- REINFORCE

### Environments
- MountainCar
- LunarLander
- Acrobot
- Pendulum
- HalfCheetah
- Hopper
- Walker2D
- Humanoid
- Custom environments

## Features

- Reinforcement Learning implementations from scratch
- Training and evaluation pipelines
- Reward monitoring and visualization
- Support for discrete and continuous action spaces
- Modular codebase for experimentation
- Ongoing additions of new algorithms and environments

## Tech Stack

- Python
- Gymnasium / OpenAI Gym
- NumPy
- Matplotlib
- PyTorch (for Deep RL implementations)

## Goals

This repository is intended to:
- Learn and implement reinforcement learning algorithms.
- Compare the performance of different approaches.
- Explore state-of-the-art techniques in deep reinforcement learning.
- Build a comprehensive portfolio of RL projects.
